# Skills

Skills de Claude Code para repetir este tipo de trabajo.

- **`simulador-de-proceso/`** — convierte una idea de proceso (pirólisis, reciclaje, tratamiento de agua, biodiésel…) en un simulador web visual: busca la información, hace el diseño preliminar, escribe y prueba las ecuaciones, y arma el presupuesto con precios de Mercado Libre. Se apoya en `pirolisis/` y `aceite-usado/` como ejemplos.

Para instalarlo en otra computadora:

```bash
git clone https://github.com/Eduardo-rico/ideas-de-mauricio.git ~/ideas-de-mauricio
ln -s ~/ideas-de-mauricio/skills/simulador-de-proceso ~/.claude/skills/simulador-de-proceso
```

Claude Code lo usa solo cuando pides una simulación así, o lo puedes llamar con `/simulador-de-proceso`.
